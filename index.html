An end-to-end data platform that converts raw e-commerce datasets into trusted analytical models. The pipeline uses Python and Parquet for ingestion, Google Cloud Storage for data storage, BigQuery as the warehouse, dbt for transformations and Kestra for workflow orchestration. Engineering practices

Built around reliable data

Data quality

dbt tests cover uniqueness, required fields and relationships across the analytical models.

02

Model integrity

Fact-to-dimension relationships and table grain are defined to support consistent analysis.

03

Metric validation

Revenue and order metrics are reconciled between fact models and reporting outputs.

04

Workflow orchestration

Kestra coordinates dependent pipeline stages instead of relying on disconnected manual steps.
